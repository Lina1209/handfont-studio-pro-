# HandFont Studio Pro

Рабочая локальная студия для рисования глифов и экспорта шрифта OpenType.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Проверка production-сборки

```bash
npm run build
npm run preview
```

Готовая сборка находится в `dist/`.

## Возможности этой версии

- Рисование символов мышью, стилусом или пальцем.
- Кириллица, латиница, цифры и знаки.
- Настройка толщины пера и ширины символа.
- Направляющие метрик шрифта.
- Автосохранение в браузере.
- Импорт и экспорт проекта JSON.
- Экспорт шрифта OpenType (.otf).
- Предпросмотр текста.
- PWA-манифест и Service Worker для установки приложения.

## Важные ограничения

- Проекты пока хранятся в браузере на конкретном устройстве. Для переноса используйте экспорт JSON.
- Облачные аккаунты, синхронизация, платежи и роли администратора не включены в эту стартовую рабочую версию. Для них нужно подключить Supabase и применить SQL из `supabase/schema.sql`.
- Не включайте платный доступ до реализации серверной проверки подписки.
- Экспорт `.otf` выполняется через opentype.js. Экспорт WOFF/WOFF2 и полноценная проверка качества шрифта — отдельный следующий этап.

## Публикация

Рекомендуемый путь — GitHub + Vercel:
1. Создайте пустой репозиторий GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. В Vercel выберите Add New → Project и импортируйте репозиторий.
4. Build Command: `npm run build`; Output Directory: `dist`.
5. Нажмите Deploy.

Vite официально описывает Git-интеграцию Vercel и сборку в `dist`: https://vite.dev/guide/static-deploy

## Supabase

В папке `supabase/` лежит начальная схема таблиц с RLS. Это заготовка базы, а не подключённая облачная авторизация. Сначала создайте проект Supabase, выполните SQL, затем добавьте URL и anon key в переменные окружения Vercel и `.env.local`.
