# HandFont Studio Pro

Браузерная студия для создания рукописных шрифтов: рисование символов, импорт заполненного бланка со скана, редактирование векторных контуров, проверка качества и экспорт шрифтов.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для production-сборки выполните `npm run build`; готовые файлы появятся в `dist/`.

## Возможности

- Рисование мышью, пальцем или стилусом.
- Кириллица, латиница, цифры и специальные знаки.
- Настройка толщины пера, направляющих и ширины символов.
- Ластик, выделение, отмена действий и редактор векторных контуров.
- Копирование отдельного знака и копирование/вставка данных знака в формате JSON.
- Семистраничный бланк для печати. Импорт одного многостраничного PDF (до 7 страниц) или до 7 отдельных фото/сканов; при загрузке отдельных файлов порядок соответствует страницам бланка.
- Выравнивание скана по четырём угловым меткам. Если одна метка потеряна, используется резервное аффинное выравнивание по трём меткам; при сильной перспективе точность ниже, поэтому результат нужно проверить вручную.
- Паспорт шрифта: автор, год, описание и условия использования; каталог символов с именем, соответствием и описанием каждого знака.
- Окно проверки качества с прокруткой внутри фиксированной панели.
- Библиотека проектов и файлов: сохраняйте проекты, созданные TTF, загруженные TTF/OTF/WOFF/WOFF2, исходные PDF-бланки и сканы PNG/JPG/WebP.
- Полная резервная копия JSON включает текущий проект, сохранённые проекты и файлы библиотеки. Восстановление заменяет содержимое библиотеки данными выбранной копии.
- Автосохранение текущего проекта в браузере на этом устройстве.
- Импорт и экспорт проекта JSON.
- Экспорт TTF и ZIP-пакета с файлами проекта и метаданными. WOFF добавляется при поддержке соответствующего сжатия браузером; файл лицензии зависит от выбранной лицензии и её настроек.
- Предпросмотр текста и установка приложения как PWA в поддерживаемых браузерах.

## Библиотека и резервные копии

Библиотека хранится локально в IndexedDB текущего браузера и не синхронизируется с облаком. Очистка данных сайта или удаление данных браузера может удалить библиотеку. Регулярно создавайте полную резервную копию JSON и храните её отдельно. Для переноса на другое устройство скачайте копию и выберите её в разделе восстановления.

Загрузка файла в библиотеку сохраняет оригинал. Само по себе это не устанавливает шрифт в систему и не распознаёт содержимое бланка.

## Ограничения

- Сейчас реализовано начертание Regular. Bold и Italic не экспортируются как отдельные настоящие начертания.
- Автосохранение и библиотека локальны для браузера/устройства; для переноса используйте резервную копию.
- Распознавание сканов помогает извлечь контуры, но не заменяет ручную проверку каждого символа.
- Успешная сборка ZIP не гарантирует принятие шрифта в Google Fonts.
- Печать паспорта и каталога выполняется через системный диалог печати браузера; в нём можно выбрать сохранение в PDF.

Приложение не требует аккаунта и облачной синхронизации.
