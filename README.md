# HandFont Studio

Локальное приложение для рисования символов и создания собственного шрифта OpenType.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для production-сборки выполните `npm run build`; результат появится в `dist/`.

## Возможности

- Рисование мышью, стилусом или пальцем.
- Кириллица, латиница, цифры и знаки.
- Настройка толщины пера, ширины символа и направляющих.
- Автосохранение в браузере на текущем устройстве.
- Импорт и экспорт проекта JSON.
- Экспорт и предпросмотр шрифта OpenType (.otf).
- Установка как PWA, если это поддерживает браузер.

Приложение работает без аккаунта и не содержит регистрации, оплаты или облачной синхронизации. Для переноса проекта используйте JSON-экспорт.
