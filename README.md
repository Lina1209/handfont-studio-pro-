# HandFont Studio Pro

Браузерная студия для создания рукописных шрифтов: рисование символов, импорт бланка со скана, редактирование векторных контуров и экспорт шрифта.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для production-сборки выполните `npm run build`; готовые файлы появятся в `dist/`.

## Возможности

- Рисование мышью, пальцем или стилусом.
- Кириллица, латиница, цифры и знаки.
- Настройка толщины пера, направляющих и ширины символов.
- Ластик, прямоугольное выделение и отмена последних действий.
- Векторный редактор контуров.
- Печать бланка и импорт заполненного бланка из изображения. Для точного выравнивания нужны все четыре угловые метки.
- Автосохранение проекта в браузере на текущем устройстве.
- Импорт и экспорт проекта JSON.
- Экспорт шрифта TTF и ZIP-пакета с TTF, WOFF (если браузер поддерживает сжатие), исходным проектом, образцом и лицензией OFL 1.1.
- Предпросмотр набранного текста и установка приложения как PWA в поддерживаемых браузерах.

## Ограничения

- Сейчас реализовано только начертание Regular. Bold и Italic не экспортируются как отдельные настоящие начертания.
- Автосохранение хранится только в текущем браузере и на текущем устройстве. Для переноса проекта скачайте JSON-исходник.
- Автоматическая проверка качества помогает находить часть ошибок, но не заменяет профессиональную проверку шрифта перед публикацией.
- Успешная сборка ZIP не гарантирует принятие шрифта в Google Fonts.

Приложение не требует аккаунта и облачной синхронизации.
